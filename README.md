# A-Plus Air CRM Platform

Next.js + Tailwind + Supabase starter for a modern HVAC CRM and booking platform.

## Features
- Responsive marketing homepage
- CRM and admin dashboards
- Lead/contact capture forms (SMS-ready fields)
- Financing + membership pages
- Service request + estimate workflow pages
- Dark/light theme toggle
- Floating call CTA
- Ready for Vercel deployment

## Setup
1. `npm install`
2. Add `.env.local`:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
3. `npm run dev`

## Deploy
Import repo into Vercel and add env vars.
